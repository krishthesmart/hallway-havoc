# Rooftop Rush

Three neon rooftops. Spikes, moving saws, and one more jump.

Play the live game: **https://krishthesmart.github.io/hallway-havoc/**

## How to play

- Run and steer with **A/D** or the **arrow keys**. Jump with **Space**, **W**, or **Up**.
- On a phone or tablet, use the on-screen left, right, and jump buttons.
- Clear spikes and moving saws, grab glowing shards, and reach each exit.
- Checkpoints save your progress. Press **R** to retry the current checkpoint instantly.
- Finish all three increasingly tricky levels. Your best score is saved in your browser.

The game is a standalone HTML canvas game: no installs, accounts, external assets, or build step required. GitHub Pages publishes the repository root through `.github/workflows/pages.yml`.
